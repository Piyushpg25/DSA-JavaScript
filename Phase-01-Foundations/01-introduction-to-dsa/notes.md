# Introduction to DSA

## What is DSA?
DSA stands for Data Structures and Algorithms.

## Data Structure
A data structure is a way of organizing and storing data so that it can be efficiently accessed and modified.

Examples:
- Array
- String
- Linked List
- Stack
- Queue
- Tree
- Graph
- Hash Map

## Algorithm
An algorithm is a step-by-step procedure used to solve a particular problem.

## Why Learn DSA?
- Improve problem-solving skills.
- Write efficient code.
- Optimize time and memory usage.
- Prepare for technical interviews.
- Understand how software works internally.
