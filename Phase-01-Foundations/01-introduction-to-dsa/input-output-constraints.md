
# Input, Output and Constraints

## Input

Input is the data provided to solve a problem.

## Output

Output is the expected result after solving the problem.

## Constraints

Constraints define the limits and conditions of the input.

They help us:

- Understand the maximum input size.
- Choose an appropriate algorithm.
- Avoid inefficient solutions.
- Understand input conditions and edge cases.

## Example

Problem: Calculate the sum of array elements.

Input:
[10, 20, 30, 40]

Output:
100

Constraint:
1 <= arr.length <= 100000

## Important

Always read the input, expected output and constraints before writing code.
